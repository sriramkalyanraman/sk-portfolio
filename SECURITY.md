# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in this portfolio website or repository, please report it privately rather than opening a public issue.

Email: srkgfm@gmail.com

Please include:
- A concise description of the issue
- The affected page or repository path
- Steps to reproduce, where safe to provide them
- Security impact and any relevant screenshots or logs

Please do not include passwords, authentication tokens, personal data, or other sensitive information in a report.

## Scope

This policy covers the public portfolio website and the code in this repository. Third-party services used by the site, including Google Analytics, Google Fonts, GitHub Pages, and FormSubmit, are operated by their respective providers and should be reported to those providers when the issue is specific to their infrastructure.

## Response

Reports will be reviewed as soon as reasonably practicable. Please allow time for validation and remediation before publicly disclosing a vulnerability.
